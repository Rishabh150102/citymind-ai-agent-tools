# CityMind AI

An AI-powered city assistant built using LangChain Agents.

## Features
- Weather Tool Integration
- News Tool Integration
- FastAPI Backend
- LangChain Agent Orchestration
- Execution Logs Visualization
- Modern AI SaaS UI

## Tech Stack
- LangChain
- FastAPI
- Next.js
- Tailwind CSS
- Tavily API
- OpenWeather API

## Run Backend

cd backend

pip install -r requirements.txt

uvicorn app:app --reload

## Run Frontend

cd frontend

npm install

npm run dev
